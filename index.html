Satu skill untuk AI coding agent supaya setiap orang di tim membangun aplikasi dengan konvensi yang sama — bukan selera model. Dilengkapi linter yang jalan di CI, karena skill tanpa penegakan akan drift dalam sebulan.

Pasang di Hermes

$ hermes skills install wilsench/company-standards-skill/skills/company-engineering-standards

Pasang di agent lain (Claude Code · Codex · Cursor)

$ curl -fsSL https://raw.githubusercontent.com/wilsench/company-standards-skill/main/install.sh | bash
# auto-deteksi ~/.hermes · ~/.claude · ~/.agents

Pakai di repo kamu

$ python3 scripts/init_standards.py . --with-checker
$ python3 scripts/check_schema.py . --json

Tiga lapis — butuh ketiganya

Kebijakan

.agent/standards.md di repo kamu, versi git. Tiap aturan punya ID supaya review bisa mengutipnya.

Prosedur

SKILL.md + references/. Tabel keputusan yang harus dilewati agent sebelum menulis DDL.

Penegakan

check_schema.py di CI. Ini yang bikin standar bertahan lintas 20 programmer.

Aturan yang ditegakkan

IDAturan
DB-01Tidak ada enum native di schema, kecuali dijustifikasi di komentar migrasi
DB-02Tidak ada magic number dibandingkan dengan kolom status
DB-03Integer status wajib punya FK ke lookup table atau CHECK
DB-04Label manusia tidak pernah disimpan sebagai nilai status
DB-05boolean hanya untuk biner sejati
Soal “00 untuk stok kosong”. Di kolom integer, 00 itu 0. Bentuk dua digit adalah format tampilan, bukan penyimpanan. Yang kamu mau sebenarnya: konstanta bernama + lookup table, supaya angka 7 yang salah ketik ditolak database.

Isi paket

  • README.md ringkasan, cara pasang, batasan jujur
  • SKILL.md prosedur 6 langkah + pitfalls
  • references/database.md tabel keputusan, contoh SQL/TS/PHP
  • references/extending.md menambah domain aturan baru
  • templates/standards.md policy file untuk repo
  • scripts/check_schema.py linter SQL · Laravel · Prisma
  • scripts/init_standards.py bootstrap policy
  • examples/bad.sql fixture yang harus gagal
  • examples/good.sql fixture yang harus lolos
